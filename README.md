# Cozmos Kingdom

An 8-bit style side-scrolling platformer starring Cozmo, the royal pup, on a
quest to reclaim the floating Kingdom from the invading Star Slimes.

Built with vanilla HTML5 canvas and JavaScript — no build step, no
dependencies. Sprites are hand-drawn pixel-art grids, and sound effects are
synthesized live with the Web Audio API.

## Play

Open `index.html` in a browser, or serve the folder locally:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000`.

## Controls

- **Arrows / WASD** — move
- **Space / Up** — jump
- **P** — pause
- **Enter** — start / retry

## Goal

Hop across 3 sky-island levels, stomp Star Slimes, collect Star-Bones, dodge
the pits, and reach the portal at the end of each level to save the Kingdom.
